Calm, clear,
and built for trust.

The visual language for the SGO platform: white space, one blue, honest type. Every component below uses the same tokens, and every text colour passes WCAG AA.

Full logo where it is at least 240px wide (hero, documents, emails, sign-in); compact logo (no subtitle) in top bars and anything smaller; icon alone for browser tabs, the app icon and the sidebar. The logo's navy and red mark the brand (logo, fund name, document headers). Buttons and links stay blue, so the next action is always the same colour.
